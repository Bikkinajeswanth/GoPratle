# GoPratle frontend

Next.js App Router app for the four-step event requirement form.
See the [root README](../README.md) for setup, testing, architecture and deployment.

```bash
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:4000
npm install
npm run dev                  # http://localhost:3000
```

Scripts: `dev`, `build`, `start`, `lint`, `typecheck`, `test` (unit), `test:e2e` (Playwright).
